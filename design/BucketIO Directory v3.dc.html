How to use
this directory

Ask for a person by name and company. BucketIO looks in its own pages first, then at the company’s house style, and only then places a paid call to Treg. Whatever comes back is written down, so nobody is looked up twice.

VFVerified — built from the house style, checked by Treg.
FDFound — Treg found them; the style was learned.

05 / The operator · scores only
Laya breaks ties. It never dials.

Laya (convaiinnovations/laya) scores the candidates when a company’s format is unsure, and breaks the tie. The pattern cache does most of the saving. Laya starts in shadow, where its picks are only logged, and turns active once the log shows it is right.
